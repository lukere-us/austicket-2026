1 Server Stack (one-time)

SSH into your VPS and install the full stack:

ssh root@YOUR_VPS_IP

apt update && apt upgrade -y
apt install -y nginx mysql-server php8.2-fpm php8.2-mysql \
  php8.2-mbstring php8.2-xml php8.2-curl git unzip
curl -fsSL https://deb.nodesource.com/setup_20.x | bash -
apt install -y nodejs
npm install -g pm2

2 Database

mysql -u root -p
CREATE DATABASE `aus-booking` CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
CREATE USER 'austicket'@'localhost' IDENTIFIED BY 'STRONG_PASSWORD';
GRANT ALL ON `aus-booking`.* TO 'austicket'@'localhost';
FLUSH PRIVILEGES;
EXIT;

Import all db/*.sql files in numeric order. Skip 002_seed_dev.sql on a live site.

5 Admin Panel — Critical Steps

Use the package-lock.json from your repo. Do not generate a new lock file on the server with an old package.json — that caused AdminJS v6 to install. 
cd /var/www/austicket/admin
pm2 stop austicket-admin 2>/dev/null || true
rm -rf node_modules
npm ci --legacy-peer-deps

# Must show adminjs@7.8.17
npm ls adminjs

Correct imports (AdminJS v7)

ImportStatus
import { AdminJS, ComponentLoader } from 'adminjs'✓ Use this
import { Adapter, Database, Resource } from '@adminjs/sql'✓ Use this
new Adapter('mysql2', { ... })✓ Use mysql2
import AdminJS from 'adminjs/lib/adminjs.js'✗ Do NOT use
new Adapter('mysql', ...)✗ Do NOT use

Build & start

NODE_ENV=production NODE_OPTIONS=--max-old-space-size=1536 \
  node -e "import('./src/adminjs.js').then(m => m.buildAdminJs())\
  .then(a => a.initialize()).then(() => console.log('OK'))"

NODE_ENV=production pm2 start src/server.js --name austicket-admin \
  --node-args="--max-old-space-size=1536"
pm2 save

6 Nginx

Create /etc/nginx/sites-available/austicket:

server {
    listen 80;
    server_name yoursite.com www.yoursite.com YOUR_VPS_IP;

    location / {
        return 200 'Site OK — API: /api/  Admin: /admin';
        add_header Content-Type text/plain;
    }

    location /api {
        alias /var/www/austicket/api;
        try_files $uri $uri/ @api;
        location ~ \.php$ {
            include fastcgi_params;
            fastcgi_param SCRIPT_FILENAME /var/www/austicket/api/index.php;
            fastcgi_pass unix:/run/php/php8.2-fpm.sock;
        }
    }

    location @api {
        rewrite ^/api/(.*)$ /api/index.php last;
    }

    location /admin {
        proxy_pass http://127.0.0.1:3001;
        proxy_http_version 1.1;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}
ln -s /etc/nginx/sites-available/austicket /etc/nginx/sites-enabled/
nginx -t && systemctl reload nginx

7 DNS — Namecheap

Use Namecheap BasicDNS (not Custom DNS) so you can edit A records.

Production checklist

  1. HTTPS enabled (Let's Encrypt)
  2. JWT_SECRET and SESSION_SECRET changed
  3. Strong MySQL password
  4. CORS includes your real frontend domain
  5. Upload/ writable by PHP
  6. Do not import 002_seed_dev.sql
  7. Create a real admin user in the database
